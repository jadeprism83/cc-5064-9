# 可变着色率（VRS）· 动态质量图

在 CPU 光线追踪器上实现的可变着色率管线。质量图不是一个跟随鼠标的圆形
高质量区，而是由**运行时声明可得的信号**逐瓦片驱动的真实自适应采样与重建：
注视移动、画面边缘（深度/物体 id 不连续）、近期重建误差、运动与重投影有效性。
全质量参考图只在离线验收时渲染，且其成本单独统计，运行时绝不先算整幅全质量图。

## 图形入口（主要使用方式）

**光栅调试视窗 `index.html` 是 VRS 的图形入口**，所有可变着色能力都接在这个视窗上：

```bash
npm run serve          # 然后浏览器打开 http://127.0.0.1:8080/
# 或任意静态服务器，例如： python3 -m http.server 8080
```

视窗包含两块画布与一组控制器：

- **真实重建画面**：稀疏几何/着色探针 → 瓦片质量图 → 锚点着色 → 双边门控双线性
  空间重建 → 相机重投影时间复用的最终画面。
- **着色率分布图**：绿=全速率(1x)，琥珀=半速率(1/4 着色)，红=1/4 速率(1/16 着色)；
  蓝框=跨带借用预算，紫框=预算受限的显露瓦片。
- **交互**：
  - 点击画面任意处移动注视点，新重点区域在 1–2 帧内恢复细节；
  - 拖动顶部/中央/底部三个区域预算滑块或全局上限，着色率分布与真实画面同时更新；
  - 勾选/取消跨带借用，观察高速目标跨入低质量带时的预算借还；
  - 悬停任意瓦片，侧栏给出该瓦片当前速率、需求分、重建误差 EMA、运动、显露窗口、
    是否借用以及**升降质量的逐条依据**。
- **运行状态面板**：帧号、着色调用占全质量比、实际/预算锚点、闪烁瓦片数、显露瓦片、
  借用瓦片、时间复用像素、重建异常像素、速率分布。异常（预算受限、无效 gather）直接
  标在着色率图上。

## 命令行（仅辅助）

命令行工具只用于自动化验收与产物生成，不替代图形入口。

| 命令 | 作用 |
| --- | --- |
| `npm run test:acceptance` | 19 项无头验收：双段栅栏显露、预算抢占、借用、响应时间、闪烁、实际省算、固定模式 |
| `npm run test:ui` | Playwright 驱动光栅调试视窗的 10 项浏览器检查 |
| `npm run samples` | 生成质量图更新样例（真实画面 + 着色率图 PPM 与决策时间线 JSON） |
| `npm run serve` | 启动图形入口的静态服务器 |

> 浏览器测试依赖 Playwright Chromium。在无 root 的 Debian 容器里若缺少系统库，
> 需准备与主机架构一致（`uname -m`，本机为 aarch64）的 bookworm 运行库，并通过
> `LD_LIBRARY_PATH` 指向本地前缀后再运行 `npm run test:ui`。

## 质量图更新样例

`npm run samples` 会把每个关键场景的代表帧写入 `out/vrs/samples/`：

- `*-picture.ppm`：该帧的真实重建画面；
- `*-ratemap.ppm`：同帧逐瓦片着色率图（颜色含义与调试视窗一致）；
- `manifest.json`：每帧的速率分布、闪烁瓦片、显露瓦片、借用瓦片、受限显露、
  着色占比与时间复用占比，用于以注视移动与边缘变化核验采样密度和时间闪烁。

PPM 可用任意图像查看器打开，或用 ImageMagick 转换：`convert a.ppm a.png`。

场景与样例帧：

| 场景 | 验证内容 |
| --- | --- |
| `occluded` | 段1：相机静止，细栅栏被滑板刚好遮住，只有眼位沿共享轨迹扫过 |
| `revealed` | 段2：眼位轨迹与段1完全相同，但遮挡物已移开，新露缝隙首次可见即预留整块精采样 |
| `saccade` | 快速扫视：新注视点 1 帧内升级，旧粗样本历史权重受重投影有效性控制 |
| `targetMotion` | 细纹理高速目标跨入顶部低质量带，借用邻区预算精采样 |
| `suddenReveal` | 静止注视下遮挡物突然移开，显露事件当帧预留 rate 1 并停用陈旧时间复用 |

## 核心机制

- **信号诚实**：运行时只使用每瓦片 4 个稀疏探针（深度/id/颜色/遮挡命中）、上一帧速率、
  注视点与重投影历史有效性。`src/reference.js` 的逐像素全质量渲染不被运行时路径导入。
- **闪烁抑制**：需求分 EMA 平滑 + 非对称迟滞 + 升级保持/降级待定时长，每帧每瓦片最多
  变一档；稳态闪烁约 18.7/3600 瓦片。显露事件的批量变化是真实遮挡响应，不计为抖动。
- **重投影门控**：以当前深度反投影到上一帧相机，校验边界、id 与 5% 深度容差；失效则
  丢弃历史、按显露窗口预留整块精采样，而不是沿用陈旧误差。
- **预算控制**：总着色预算 = 探针 + 锚点统一封顶；先从普通瓦片回收、最后才压缩显露，
  压缩部分标为「预算受限」。区域预算可编辑并支持跨带借用，全局下限钳制到
  探针 + rate-4 锚点网格的物理可行值。
- **固定分区可切换**：质量图模式可在「动态自适应」与「初版固定分区」之间切换，
  固定模式仍输出合法速率并正常重建。

## 目录

```
index.html              图形入口：光栅调试视窗
src/app.js              视窗应用控制器（场景时钟、预算编辑、单步/播放）
src/ui.js               DOM 与画布接线
src/vrs.js              VRS 管线：探针、质量图决策、预算、锚点着色与重建
src/dynamics.js         动态场景：栅栏、滑板遮挡、高速目标与五个场景
src/reference.js        离线全质量参考与 PSNR（成本单独统计）
src/scene.js shading.js 场景几何、相机与材质
tools/                  验收、UI 测试、静态服务器、样例生成、PPM 输出
out/vrs/samples/        质量图更新样例产物
```
